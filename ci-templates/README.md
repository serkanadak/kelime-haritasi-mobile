# Kelime Haritası - GitHub Actions CI/CD Kurulum Rehberi

Bu klasordeki deploy.yml dosyasi, otomatik Android (APK/AAB) ve iOS (IPA/TestFlight) derleme islemlerini GitHub Actions uzerinde kosmak uzere hazirlanmistir.

## GitHub Actions Nasil Aktif Edilir:
1. Deponuzun ana sayfasinda Add file -> Create new file butonuna basin.
2. Dosya adi alanina: .github/workflows/deploy.yml yazin.
3. Icerik olarak bu klasordeki ci-templates/deploy.yml icerigini yapistirin ve kaydedin.
